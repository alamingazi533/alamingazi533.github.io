Facebook Two-Factor Authentication চালু করার নিয়ম — Authenticator অ্যাপ সহ ধাপে ধাপে গাইড

লেখক: মোঃ আলামিন ইসলাম · 09/10/2026

ফেসবুক আইডি হ্যাক হওয়ার ভয় থাকলে সবচেয়ে কার্যকর সুরক্ষা হলো Two-Factor Authentication (2FA)। এতে পাসওয়ার্ড জানলেও কেউ আপনার আইডিতে ঢুকতে পারে না, কারণ লগইনের সময় আরেকটা কোড লাগে। এই পোস্টে সহজ ভাষায় বলছি এটা কী এবং কীভাবে চালু করবেন।

Two-Factor Authentication কী?

সাধারণ লগইনে শুধু পাসওয়ার্ড লাগে। 2FA চালু থাকলে পাসওয়ার্ডের পর একটা অতিরিক্ত কোড দিতে হয়। এই কোড আসে আপনার ফোনের এসএমএসে, বা Authenticator অ্যাপে, বা নিরাপত্তা চাবিতে। তাই অন্য কেউ পাসওয়ার্ড জেনে ফেললেও ঢুকতে পারে না।

কোন পদ্ধতি বেছে নেবেন?

ফেসবুক সাধারণত এই বিকল্পগুলো দেয় (আপনার অ্যাপে কোনোটা না-ও থাকতে পারে):

  • Authentication app: Google Authenticator বা এ ধরনের অ্যাপ। এটা সবচেয়ে নিরাপদ ও ইন্টারনেট ছাড়াও কাজ করে।
  • Text message (SMS): ফোন নম্বরে কোড আসে। সহজ, তবে নেটওয়ার্ক না থাকলে কোড আসতে দেরি হতে পারে।
  • Security key: আলাদা হার্ডওয়্যার চাবি। সাধারণ ব্যবহারকারীর জন্য জরুরি নয়।

সাধারণ ব্যবহারকারীর জন্য Authentication app সবচেয়ে ভালো। না পারলে SMS ব্যবহার করুন।

মোবাইল অ্যাপে চালু করার ধাপ

ধাপ ১: ফেসবুক অ্যাপে মেনু (তিন দাগ) থেকে Settings & privacy → Settings এ যান।

ধাপ ২: Accounts Center চাপুন, তারপর Password and security এ যান।

ধাপ ৩: Two-factor authentication চাপুন এবং যে আইডিতে চালু করবেন সেটা বেছে নিন।

ধাপ ৪: Authentication app বা Text message, যেটা চান বেছে নিন।

ধাপ ৫ (Authentication app হলে): ফোনে Google Authenticator বা অন্য কোনো Authenticator অ্যাপ ইনস্টল করুন। ফেসবুক যে কোড বা QR দেখাবে সেটা অ্যাপে যোগ করুন। অ্যাপ ৬ অঙ্কের একটা কোড দেখাবে, সেটা ফেসবুকে লিখে Continue দিন।

ধাপ ৬ (SMS হলে): আপনার ফোন নম্বর দিন। ফেসবুক কোড পাঠাবে, সেটা লিখে নিশ্চিত করুন।

ধাপ ৭: শেষে "Done" বা "Finish" দিন। এখন আপনার 2FA চালু।

Recovery code বা Backup code অবশ্যই সংরক্ষণ করুন

2FA চালুর সময় ফেসবুক কিছু Recovery code দেয়। এগুলো না হারানোই ভালো, কারণ ফোন হারালে বা অ্যাপ মুছে গেলে এই কোড দিয়ে ঢুকতে পারবেন। কোডগুলো:

  • স্ক্রিনশট না নিয়ে একটা নিরাপদ জায়গায় লিখে রাখুন।
  • অন্য কাউকে দেখাবেন না।
  • প্রতিটা কোড একবারই কাজ করে।

লগইনের সময় কী হবে?

নতুন ডিভাইস বা নতুন জায়গা থেকে লগইন করলে ফেসবুক কোড চাইবে। কোডটা Authenticator অ্যাপ বা এসএমএস থেকে নিয়ে বসান। পরিচিত ডিভাইসে "Trust this device" বা "Remember this browser" দিলে বারবার কোড চাইবে না।

কোড কাজ না করলে

  • ফোনের সময় ও তারিখ স্বয়ংক্রিয় (automatic) করে নিন। Authenticator অ্যাপের কোড সময়ের ওপর নির্ভর করে।
  • ফোন নতুন হলে বা অ্যাপ মুছে গেলে Recovery code ব্যবহার করুন।
  • কোড এসএমএসে না এলে আমাদের সাইটের "Confirmation code আসছে না" পোস্টটি দেখুন।

যা করবেন না

  • 2FA কোড, Recovery code বা পাসওয়ার্ড অন্য কাউকে বলবেন না। ফেসবুকের লোক পরিচয় দিয়ে কেউ কোড চাইলে সেটা প্রতারণা।
  • অচেনা সাইটে বা অ্যাপে কোড বসাবেন না।
  • "2FA খুলে দেব" বলে টাকা চাওয়া কাউকে বিশ্বাস করবেন না।

সংক্ষেপে মনে রাখুন

Settings → Accounts Center → Password and security → Two-factor authentication এ গিয়ে Authentication app বেছে নিন। Recovery code নিরাপদ জায়গায় রাখুন। কারও সাথে কোড শেয়ার করবেন না।

আপনার আইডির সুরক্ষা নিয়ে সমস্যা থাকলে আমাদের সাইটের "সমস্যা জানান" ফর্মে জানান।

আপনার সমস্যাও কি এমন? আমাদের জানান — সমাধানে সাহায্য করব।

WhatsApp-এ সমস্যা জানানলাইক ও মন্তব্য করুন

এই লেখা শুধু সাধারণ তথ্যের জন্য। আমরা Meta, Facebook বা Google-এর অফিসিয়াল প্রতিনিধি নই; কোনো অ্যাকাউন্ট ফেরত পাওয়ার নিশ্চয়তা দিই না।

আরও পড়ুন

  • WhatsApp "Verification Code" আসছে না — ৬ অঙ্কের কোড না পেলে কী করবেন
  • Instagram "Verify Your Identity" — ভিডিও সেলফি চাইলে কী করবেন ও কীভাবে দেবেন
  • ফেসবুকে "Login from Unknown Device" বা "Someone Tried to Log In" — অচেনা ডিভাইস থেকে লগইনের মেসেজ এলে কী করবেন
  • কেউ আমার নামে ফেসবুকে ফেক প্রোফাইল খুলেছে — Impersonation রিপোর্ট করার সম্পূর্ণ নিয়ম
  • YouTube "Your Channel Has Been Terminated" — কেন হয়, কীভাবে আপিল করবেন ও চ্যানেল ফিরে পাওয়ার উপায়
  • TikTok "Your Account Was Permanently Banned" — কেন ব্যান হয় ও কীভাবে আপিল করবেন
