Instagram Security Code আসছে না — Two-Factor লগইনে কোড না পেলে কী করবেন

লেখক: মোঃ আলামিন ইসলাম · 10/10/2026

ইনস্টাগ্রামে Two-Factor Authentication চালু থাকলে লগইনের সময় ইমেইল বা এসএমএসে একটা কোড আসে। কিন্তু অনেক সময় সেই কোড আসেই না, তখন আইডিতে ঢোকা যায় না। এই পোস্টে সহজ ভাষায় কারণ ও সমাধান বলছি। কোড কেন আসে না? ভুল বা পুরোনো ফোন নম্বর/ইমেইল। ইমেইলের স্প্যাম ফোল্ডারে চলে যাওয়া। নেটওয়ার্ক বা এসএমএস সমস্যা। বারবার কোড চাওয়া। এতে ইনস্টাগ্রাম সাময়িকভাবে কোড পাঠানো সীমিত করে। নম্বর ব্লক বা ডু-নট-ডিস্টার্ব মোড। ভিপিএন ব্যবহার করা। ইনস্টাগ্রামে সাময়িক সমস্যা। ধাপে ধাপে সমাধান ধাপ ১: ইমেইল ও এসএমএস ভালো করে দেখুন ইনবক্সে না পেলে Spam, Promotions ও Updates ফোল্ডার দেখুন। এসএমএস অ্যাপে স্প্যাম বা ব্লক করা বার্তাও দেখুন। ধাপ ২: ২-৩ মিনিট অপেক্ষা করুন কোড আসতে একটু সময় লাগতে পারে। সাথে সাথে বারবার "Resend" চাপবেন না। ধাপ ৩: ফোনের নেটওয়ার্ক ঠিক করুন ফোন রিস্টার্ট দিন, এয়ারপ্লেন মোড চালু-বন্ধ করুন। ডু-নট-ডিস্টার্ব বন্ধ রাখুন। ভিপিএন বন্ধ রাখুন। ধাপ ४: অন্য উপায় বেছে নিন লগইন পেজে "Try another way" বা "Use backup code" থাকলে সেটা ব্যবহার করুন। Authenticator অ্যাপ থাকলে সেটার কোড দিন। ধাপ ৫: Backup code ব্যবহার করুন Two-Factor চালুর সময় ইনস্টাগ্রাম কিছু Backup code দিয়েছিল। যদি সংরক্ষণ করে থাকেন, তার একটা এখানে ব্যবহার করতে পারেন। প্রতিটা কোড একবারই কাজ করে। ধাপ ৬: পরিচিত ডিভাইস থেকে চেষ্টা করুন যে ফোনে আগে লগইন করা আছে সেখানে গিয়ে Settings → Accounts Center → Password and security → Two-factor authentication দেখুন। ধাপ ৭: কিছুক্ষণ পর আবার চেষ্টা করুন বারবার চাওয়ার কারণে আটকে গেলে এক ঘণ্টা বা কয়েক ঘণ্টা পর আবার চেষ্টা করুন। কিছুতেই না হলে লগইন পেজের "Need more help?" ব্যবহার করুন। ইনস্টাগ্রামের Help Center-এ গিয়ে "I can't log in because I don't get the security code" অংশ দেখুন। অফিসিয়াল অ্যাপ ছাড়া অন্য কোথাও কোড চাইবেন না। যা করবেন না "টাকা দিলে কোড পাঠিয়ে দেব" বললে বিশ্বাস করবেন না। কোড অন্য কাউকে বলবেন না। অচেনা লিংকে ক্লিক করবেন না। ভবিষ্যতের জন্য আইডিতে সঠিক ও চালু ইমেইল আর ফোন নম্বর রাখুন। Backup code গুলো একটা নিরাপদ জায়গায় সংরক্ষণ করুন। সম্ভব হলে এসএমএসের বদলে Authenticator অ্যাপ ব্যবহার করুন। সংক্ষেপে মনে রাখুন কোড না এলে প্রথমে স্প্যাম, নেটওয়ার্ক আর নম্বর ঠিক আছে কি না দেখুন। "Try another way" বা Backup code ব্যবহার করুন। কারও সাথে কোড শেয়ার করবেন না। আপনার আইডিতে এই সমস্যা হলে আমাদের সাইটের "সমস্যা জানান" ফর্মে জানান।

আপনার সমস্যাও কি এমন? আমাদের জানান — সমাধানে সাহায্য করব।

WhatsApp-এ সমস্যা জানানলাইক ও মন্তব্য করুন

এই লেখা শুধু সাধারণ তথ্যের জন্য। আমরা Meta, Facebook বা Google-এর অফিসিয়াল প্রতিনিধি নই; কোনো অ্যাকাউন্ট ফেরত পাওয়ার নিশ্চয়তা দিই না।

আরও পড়ুন

  • Facebook "Your Account Has Been Disabled" — কেন হয় ও আপিল করার সঠিক নিয়ম
  • Instagram-এ Block, Restrict ও Mute-এর পার্থক্য কী — বিরক্তিকর কাউকে সামলাবেন কীভাবে
  • Instagram অ্যাকাউন্ট সাময়িক বন্ধ (Deactivate) বা মুছে ফেলার নিয়ম — আগে কী জানা দরকার
  • Gmail বা Google অ্যাকাউন্টে ঢুকতে পারছেন না — Account Recovery করার সহজ নিয়ম
  • Messenger-এ লগইন করা যাচ্ছে না — কারণ ও ধাপে ধাপে সমাধান
  • Instagram "We Suspect Automated Behavior on Your Account" — কেন আসে ও কী করবেন
